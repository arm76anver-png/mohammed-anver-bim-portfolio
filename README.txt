MOHAMMED ANVER — BIM PORTFOLIO WEBSITE

HOW TO VIEW
1. Download and extract this ZIP file on your Windows laptop.
2. Open the extracted folder.
3. Double-click index.html to view the website in Chrome or Edge.
4. To edit the files, open the folder in Visual Studio Code.

WHAT IS ALREADY PREPARED
- Personal homepage and professional introduction
- Mechanical MEP and Public Health expertise
- Revit, Navisworks, AutoCAD and ACC skills
- HVAC, plumbing/drainage and clash-detection project showcase sections
- BIM delivery process and consolidated responsibilities
- Contact section and responsive mobile navigation

IMPORTANT — BEFORE PUBLISHING
- Review all wording and confirm the experience duration and contact details.
- Add your CV PDF to the assets folder with this exact filename:
  Mohammed_Anver_CV.pdf
- Replace the illustrated sample project artwork with screenshots of your own work.
- Add actual employer names, job titles, dates and project details only after checking them.
- Do not publish confidential client or employer information without permission.
- The website uses Google Fonts when internet access is available.

PUBLISHING
This is a static website. It can be published free using GitHub Pages:
1. Create/sign in to GitHub.
2. Create a new public repository named mohammed-anver-bim-portfolio.
3. Upload index.html, style.css, script.js and the assets folder.
4. Open repository Settings → Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. GitHub will provide your public website address.

This starter does not include a working contact-form backend or a purchased custom domain.


OPPORTUNITIES & APPOINTMENTS
- The job opportunity button opens an email addressed to you.
- The appointment request button opens a pre-filled email draft with purpose, date, time and meeting type.
- This is an appointment request, not an automatic confirmed booking.
- To offer live selectable appointment times, create a booking page with a scheduling provider (for example Calendly), then replace the appointment email link with your personal booking URL or embed code.
